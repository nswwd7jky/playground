# TIL: Go 1.23 range-over-func

Just read about iter.Seq and the new `for range` over functions.

- `iter.Seq[V]` is `func(yield func(V) bool)`
- `iter.Pull` gives you a pull-based iterator, but push style is simpler for most cases.

Example from memory:

```go
func Backward(s []string) iter.Seq[string] {
    return func(yield func(string) bool) {
        for i := len(s)-1; i >= 0; i-- {
            if !yield(s[i]) {
                return
            }
        }
    }
}
```

Useful for microservice batch jobs where we need lazy iteration over large result sets.
